# 快速开始
键盘配置与 Vim 类似。

## 命令
你可以输入 `:` 来输入命令。
以下是一些常用命令：
|命令    |描述                                        |示例                    |
|-------|--------------------------------------------|-----------------------|
|`:q`   |退出应用程序                                  |`:q`                   |
|`:o`   |打开库文件（你可以在 /examples 目录下查看示例）   |`:o examples/test.yaml`|

## 选择
你可以使用 上(K), 下(J), 左(H) 和 右(L) 来选择库、书或条目。

## 伙伴 (Buddy)
Buddy 是这个应用中的一个小彩蛋。
它会说一些简单的话，避免枯燥。
