# Quickstart
The keyboard configuration is similar to vim.

## Commands
You can type `:` to input commands.
These are some common commands:
|command|description                                                    |example                |
|-------|---------------------------------------------------------------|-----------------------|
|`:q`   |Quit the application                                           |`:q`                   |
|`:o`   |Open a lib file (you can see examples in /examples directory)  |`:o examples/test.yaml`|

## Selecting
You can use Up(J), Down(K), Left(H) and Right(L) to select libs, books or entries.

## Buddy
The buddy is a small egg in this app.
It could say some simple sentences avoiding boring.
